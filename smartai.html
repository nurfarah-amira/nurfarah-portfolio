PROJECT DETAILS

SmartAI – AI-Powered Course Generator

An AI-powered web application designed to generate structured e-learning courses from uploaded learning materials.

Project Overview

SmartAI is an AI-powered course generator designed to assist users in creating structured educational content using artificial intelligence.

The system allows users to upload learning materials, generate structured course content, create lesson materials, and manage generated courses through a web-based platform.

Technologies Used

PHP MySQL JavaScript HTML CSS AI

Key Features

  • AI-powered course content generation.
  • Upload learning materials for AI processing.
  • Generate structured course modules.
  • Generate lesson content using AI.
  • Manage generated courses.
  • View generated course content.
  • Generate and download course documents.

My Contribution

Developed web features, implemented database integration, worked on AI-powered course generation, designed user interface components, and integrated the main management features of the system.
