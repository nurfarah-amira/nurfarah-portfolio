PROJECT DETAILS

H5P – Interactive Learning Content

An interactive learning content project created using H5P to support engaging and interactive digital learning experiences.

Project Overview

This project involved exploring H5P as an interactive content authoring tool for educational purposes.

The interactive learning materials were developed to help lecturers create engaging digital learning experiences and were uploaded to the UCreds platform.

Technologies Used

H5P HTML CSS JavaScript UCreds

My Contribution

  • Explored H5P interactive content types.
  • Created interactive learning materials.
  • Developed a guide for lecturers using H5P.
  • Designed the course development workflow.
  • Uploaded completed H5P modules to UCreds.
